CLI reference

Explicit by design.

Choose one action. Version and path options are validated against that action before anything changes.

CommandBehavior
--install, -iInstall and activate upstream latest, or the version passed with -v.
--list, -lList managed versions and their installation directories.
--switch, -sSwitch to the newest installed release by default. Missing versions require confirmation before installing.
--uninstall, -uRemove the active version by default; use -v VERSION to choose another. Then activate the newest remaining version.
--verbose 0..2Default output, operational detail, or diagnostics. Level zero is identical to omitting the flag.
--log [DIR]Write a timestamped run log to the script directory or an existing writable directory.

Switch and uninstall discover the install root from the active managed symlink. If discovery fails, they refuse to modify the installation.

Supply-chain checks

Integrity is a gate, not a warning.

scrcpy Version Manager pins the upstream maintainer's primary-key fingerprint, verifies the detached signature on the release checksum manifest, and checks the matching archive digest. Extraction begins only after successful verification.

Requirements

Linux x86-64

Requires Bash, curl, GnuPG, checksum and archive utilities, and administrative privileges for system-wide installs. ADB is optional for installation but required to connect Android devices. Missing packages are explained and can be offered for installation through supported package managers.
